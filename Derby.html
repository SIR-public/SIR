Object Biography: Derby

Derby is a Java-based database management system supplied by the open source Apache project, available at http://db.apache.org/derby. It provides the same functionality as MySQL and other DBMS systems and is based on the Java, JDBC and SQL standards. Derby is classified as a small footprint DBMS and can be embedded into other Java solutions.

We obtained several sequential, previously-released versions of Derby, each provided with a developer supplied test suite. The tests in each version's test suite were initially intended to be run in total. Consequently the preparation done by the SIR was to remove nondeterministic outputs and individualize the tests and the test results for comparison between good and faulted variants of each version.
