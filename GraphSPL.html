Object Biography: Graph Software Product Line

GraphSPL is a graph analysis package that embodies the architectural features of a software product line. While GraphSPL is a small SPL example program, it can be composed into a family of 42 products (instances). The version provided here has been packaged as a typical SIR test subject including scripting to automate the testing across all product instances. It has core, mandatory, and optional features, enabling experiments on product line feature variablity and composition.

The GraphSPL subject includes documentation and feature model definition files (in Bali BNF grammar) of the product line which are compatible with the AHEAD tool suite (ATS) for automated SPL step-wise refinement and model analysis.

The original Graph SPL was created by Lopez-Herrejon and Batory [1].

[1]R. E. Lopez-Herrjon and D. S. Batory. A standard problem for evaluating product line methodologies. in proceedings of the International Conference on Generative and Component-Based Software Engineering (GCSE'01), pp 10-24, 2001
