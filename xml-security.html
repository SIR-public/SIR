Object Biography: XML-security

XML-security is a component library implementing XML signature and encryption standards, supplied by the XML subproject of the open source Apache project. It is available at http://santuario.apache.org/javaindex.html (or the original Apache version upon which this artifact is based.) It currently provides a mature implementation of Digital Signatures for XML, with implementation of encryption standards in progress.

We obtained several sequential, previously-released versions of XML-security, each provided with a developer supplied JUnit test suite. In each version, faults were seeded using the fault seeding procedure described in the Java Fault Seeding Process.
